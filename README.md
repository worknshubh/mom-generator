# 🎙️ MOM Generator

An AI-powered tool that converts meeting audio into structured **Minutes
of Meeting (MOM)** automatically.\
It helps users save time by summarizing discussions into clear,
organized points.

------------------------------------------------------------------------

## ✨ Features

-   🎤 Upload or record meeting audio\
-   🧠 AI-based transcription & summarization\
-   📝 Generates clean and structured MOM\
-   ⚡ Fast and easy to use\
-   🤖 Powered by Mistral AI

------------------------------------------------------------------------

## 🚀 Getting Started

1.  Clone the repository

``` bash
git clone https://github.com/worknshubh/mom-generator.git
```

2.  Navigate into the project

``` bash
cd mom-generator
```

3.  Create a `.env` file and add your API key

```{=html}
<!-- -->
```
    MISTRAL_API_KEY=your_api_key_here

4.  Run the server

``` bash
uvicorn main:app --reload
```

------------------------------------------------------------------------

## 💡 How It Works

1.  Upload or record your meeting audio\
2.  The system transcribes the audio\
3.  AI processes and summarizes the content\
4.  Generates structured Minutes of Meeting
